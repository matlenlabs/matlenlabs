# Matlen Labs

Hi, I'm Matt English, a software developer. Matlen Labs is where I build, and write up, experiments in local AI, home infrastructure and personal apps.

## Now building

- **Home AI lab:** family storage and photos on TrueNAS, with Claude for planning and reasoning and local models (Ollama) for private, bulk work like tagging and transcription.
- **Data rescue and dedupe:** consolidating years of old drives and cloud accounts into one organized, backed-up library, starting with a read-only drive inventory tool.
- **Personal apps:** small tools that run on my own hardware and use AI where it actually helps.

## How I work

- **Local first.** Private data stays on hardware I own.
- **Copy, never move.** Nothing is deleted until it exists in two places.
- **Everything as code.** Setup, config and decisions live in git.
